## 📝 Descripción  
  
Portfolio personal desarrollado con React y Vite, presentando mis habilidades, proyectos y experiencia como desarrollador. El sitio está completamente optimizado y desplegado en GitHub Pages.  
  
## ✨ Características  
  
- 🎨 Diseño moderno y responsive  
- ⚡ Carga rápida con Vite  
- 📱 Compatible con dispositivos móviles  
- 🎯 Navegación intuitiva  
- 🚀 Desplegado automáticamente en GitHub Pages  
  
## 🛠️ Tecnologías Utilizadas  
  
- **Frontend Framework:** React 19.1.1  
- **Build Tool:** Vite 7.1.2  
- **UI Framework:** Bootstrap 5.3.8  
- **Iconos:** React Icons, Bootstrap Icons, FontAwesome  
- **Routing:** React Router DOM 7.8.2  
- **Deployment:** GitHub Pages

## 🚀 Instalación y Uso  
  
### Prerrequisitos  
  
- Node.js (versión 16 o superior)  
- npm o yarn  
  
### Instalación  
  
1. Clona el repositorio:  
```bash  
git clone https://github.com/LuisDavidTF/Portfolio.git  
cd Portfolio
``` 
Instala las dependencias:
```bash
npm install
```
Inicia el servidor de desarrollo:
```bash
npm run dev
````
Abre tu navegador en ````http://localhost:5173````

## 📦 Scripts Disponibles

- ```npm run dev``` - Inicia el servidor de desarrollo
- ```npm run build``` - Genera la build de producción
- ````npm run preview```` - Previsualiza la build de producción
- ````npm run lint```` - Ejecuta ESLint para verificar el código
- ````npm run deploy```` - Despliega el sitio en GitHub Pages

## 🌍 Despliegue

El portfolio está configurado para desplegarse automáticamente en GitHub Pages. Para desplegar cambios:

```bash
npm run deploy
```
Este comando ejecuta automáticamente el build y publica los cambios en la rama ``gh-pages.``
